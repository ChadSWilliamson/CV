Vigía Recon

Outside-In Attack Surface Monitor

Working project · built solo from scratch

Vigía (Spanish for "lookout") watches a business's domains the way an attacker would, from the outside. Every day it scores each domain 0–100, flags what an attacker would notice first, and emails the owner before an expired certificate, a dangling DNS record, or a leaked config file turns into an incident.

  • Daily 0–100 security score and letter grade per domain
  • Email security: SPF, DMARC, and DKIM posture
  • Web exposure: security headers, TLS config, server fingerprinting
  • Vulnerability intel: open ports and CVEs, with CISA KEV and EPSS context
  • Active checks for leaked .git, .env, and backups, gated behind DNS ownership verification
  • SSL, domain expiry (RDAP/WHOIS), DNS changes, and CT log monitoring
  • Subdomain takeover detection (dangling CNAME checks)
  • Uptime every 15 minutes, with deduplicated email alerts via Resend
